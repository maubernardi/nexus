# Elenco dei comuni italiani (ISTAT)

`Elenco-comuni-italiani.csv`: file pubblicato dall'ISTAT
(<https://www.istat.it/classificazione/codici-dei-comuni-delle-province-e-delle-regioni/>), scaricato il 09/11/2026,
così com'è (CSV con `;`, Latin-1). Licenza: Creative Commons Attribuzione 4.0 (CC BY 4.0), fonte ISTAT.

Serve solo alla demo e allo sviluppo locale (profilo `seed`, US-114): se l'elenco è vuoto, all'avvio si carica da qui.
In produzione l'ADMIN carica il file aggiornato dalla pagina «Cataloghi».
